# UJIRA demo

A preview of UJIRA, non-custodial payouts on Stellar: the marketing site and a testnet dashboard.

- `index.html`: the website
- `instaward.html`: one page that checks the mandate contract, the payout engine and the MCP server live against Stellar testnet. It reads `data/` as a fallback when GitHub is not reachable; put the demo video link in `data/page.json`.
- `app.html`: the dashboard. Connect a Stellar wallet set to Testnet. Nothing here touches mainnet or real money.

Photos are from Unsplash and credited on the page.
